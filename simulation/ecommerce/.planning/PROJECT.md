# ShopNova — Modern E-Commerce Platform

## What This Is
A full-featured e-commerce platform for small businesses selling physical products. Customers browse products, manage a shopping cart, and complete checkout with Stripe payments.

## Core Value
Beautiful, fast product browsing experience with frictionless checkout.

## Tech Stack
- Next.js 16 (App Router)
- TypeScript 6
- PostgreSQL 18 + Prisma 7
- Tailwind CSS v4 + shadcn/ui
- Stripe for payments
- Zod for validation
- Vitest for testing
- Redis for cart session storage
