8 — Cross-Cutting Systems

Markdown file tracking execution state, decisions, warnings, user preferences, rejected approaches. Written by execution, read by factory for knowledge propagation. Auto-compacts when large, archived on phase complete.

Knowledge Base
Persistent learnings surviving across milestones. Auto-promoted from ledger on archive (decisions, warnings, pitfalls). Jaccard dedup (>80% similarity). Filtered by module relevance, injected into agent prompts.

SQLite database via tree-sitter AST parsing. Files, symbols, deps, modules, capabilities. Queried by factory (context + risk), verification (contracts + cycles), updater (incremental). Snapshots saved before/after execution.
